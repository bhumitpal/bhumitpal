## 👋 About me

I build immersive XR experiences and games in **Unity and C#** that people actually learn from.

- 🥽 **XR / Game Developer at [Xpan Interactive](https://xpan.ca)** (full-time, remote from Toronto). I've shipped 7 training and learning products for **Meta Quest, HoloLens 2, and WebGL**.
- 🏆 My SAIT lathe **"Jump Scare" VR safety simulation** won **Silver at the 2026 Muse Creative Awards**.
- 🎲 **Co-founder of Havoc Studios.** We're building **Holo Havoc**, a multiplayer mixed-reality tabletop strategy game funded by the **Canada Media Fund (CMF) Conceptualization Program**.
- 🎬 I run **[Game Feel Clinic](https://www.youtube.com/@GameFeelClinic)**: short breakdowns of why great game mechanics *feel* good, each with a playable Unity demo.
- 🧪 I spent 6+ years across game development, VR, mixed reality, and QA, including Oculus VR certification and PS4/Xbox One testing.
- 📫 I'm open to **XR Developer, Unity Developer, and Game Developer** roles (Toronto, hybrid, or remote).

## 🛠️ What I build

| Area | Details |
|---|---|
| **Gameplay** | Gameplay, UI, animation, and camera programming (Cinemachine), physics, raycasting, input |
| **Game AI** | State machines, NavMesh, flocking, behavior synced to animation |
| **XR** | VR and MR interaction design for Meta Quest and HoloLens 2, spatial audio, haptics |
| **Multiplayer** | Photon PUN 2, Unity Gaming Services, 4-player co-op WebGL |
| **Tools** | Unity editor tools, procedural generation, PowerShell automation |
| **Learning tech** | LMS integration, SCORM, simulation-based training, digital twins, AI-assisted trainers |
| **Optimization** | Object pooling, caching, coroutine batching for Quest and WebGL |
